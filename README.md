DealCheck — a Black Friday 2026 deal finder. Twelve deals, checked one by one on 27 November 2026: six checked live on the store's own product page, six read from published deal roundups. Each deal carries its store, sale price, usual price, discount, check time and source, plus a badge that says whether it is really a deal — Real deal (20% off or more, confirmed by two or more independent sources) or Good deal. Search and filters by category, store and discount, with sorting by biggest discount, biggest saving or lowest price. A static site that runs from its own files with no network request, on desktop and on a phone.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `app/index.html` in a browser, or serve `app/` with any static server, for example `python3 -m http.server` inside `app/`.
